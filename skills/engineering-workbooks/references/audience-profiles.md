# Select and inspect audience views

Ask/infer the intended audience from the requested share task; do not export every
profile by default. P02 supports these concrete profiles:

| Profile | Primary detail |
| --- | --- |
| business | Needs, stories, criteria, outcome roadmap, milestones, user-facing changes/guidance |
| engineering | Requirements, design/ADR/contracts, tasks, bindings, tests/release detail and narrative |
| qa | Requirements, stories/criteria, defined cases, observed runs and release plan |
| operations | Rollout/recovery, compatibility, support/guidance, contracts and test/release facts |
| executive | Outcomes, milestones and release scope/limits |

Every profile retains source manifest, trace identities, recorded states and material
test/release/risks limitations. Check declared omissions and full-source links; a
short view is not a complete design or acceptance record. Engine readiness is a
recorded source result, not approval. Do not hide relevant uncertainty for executives.

Inspect named tables/filtering, frozen identity columns, wrap/row heights, labels,
source hyperlinks and feedback cells. Feedback is labelled as well as yellow, so
color is not the sole cue. Relative source links require accompanying files in the
shared structure. XLSX content can be retained but require opening a long cell/source;
wide print tables span horizontal A3 pages. Do not describe a printed excerpt as
complete or an export as an accessible PDF publishing system.

Verify source parity and relevant profile facts, then office open/save or rendering
when available. Record exact application/version and actual outcomes. LibreOffice
results do not certify Excel desktop or assistive behavior. No calculated model is
provided; general formula modeling is outside this skill. Basis:
[P02](../../../docs/skills/engineering-artifact-catalogue/P02.md), original contract
profiles and PLAN S33–S37; native Excel/assistive review remains a separate check.
