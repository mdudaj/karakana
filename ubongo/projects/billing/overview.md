# Billing Overview

The `billing` skillpack is Karakana's profile for the NIMR Django billing and
GePG reconciliation project. Read-only repository metadata confirmed NIMR
ownership on 2026-10-01. The local `../billing` checkout is optional and was
absent during this review; do not treat this memory as a code audit.

Start project work by locating the current checkout, reading its own contract
and README, then checking the task's billing workflow and tests. The default
branch README names invoice/receipt, payment operator and deployment planning
documents; verify their current content before using them as requirements.
Use `gepg-billing` and `django-debugging` for applicable work.
