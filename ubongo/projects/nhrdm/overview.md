# NHRDM Overview

NHRDM is the NIMR health research data management repository registered by the
`nhrdm` skillpack. Read-only repository metadata confirmed NIMR ownership on
2026-10-01. Its default branch README identifies an InvenioRDM instance. The
local `../nhrdm` checkout is optional and was absent during this review.

For project work, locate a current checkout and read its contract, README,
configuration, custom modules and tests. Use `invenio-framework` for applicable
record, service, resource, permission and index work. This memory does not
certify current NIMR-specific requirements or the deployment state.
