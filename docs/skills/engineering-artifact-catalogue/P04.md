Discover or inspect a skill, then compose a prompt for an explicitly requested task:

```bash
karakana skill list
karakana skill show engineering-requirements
karakana plan --project karakana --use-skillpack \
  --skill engineering-design-records --task "Plan the requested ADR review"
```

Replace project/skill/task with the actual authorized scope. `plan` composes a
model-ready prompt by default; it neither calls a model nor authors an artifact.
It selects one body explicitly or the first required skill when omitted. Optional
names are visible context, not automatic keyword routing or universal body loading.
