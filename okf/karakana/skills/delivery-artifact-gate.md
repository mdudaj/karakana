# Delivery Artifact Gate

This skill makes product requirements documents, requirements notes, user stories, acceptance criteria, ADRs, UX notes, schema contracts, traceability matrices, readiness checks, tests/evals, and handoffs part of the implementation boundary.

Non-trivial work must be evidence-backed: user input, repository docs, OKF concepts, memory, schemas, traces, evals, research, or explicit assumptions with validation paths. The artifact gate blocks "chat-only" implementation plans when the task needs durable requirements, UX, architecture, data, safety, or verification context.
